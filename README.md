# CodeAlpha_Stock-Portfolio-Tracker

This Stock Portfolio Tracker is a Python project built during a CodeAlpha coding internship to calculate and summarize stock investments using dictionaries, user input handling, and basic arithmetic operations. Users can enter stock ticker symbols and share quantities against predefined stock prices to view individual holding values, total portfolio investment, and an optional saved summary report (`.txt` or `.csv`). To run the project, clone or download the repository and execute `python stock_portfolio_tracker.py` in your terminal.
